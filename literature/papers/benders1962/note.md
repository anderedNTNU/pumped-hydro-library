# Partitioning procedures for mixed-variables programming (Benders, 1962)

_Page mapping: PDF page n = journal page 237 + n (journal pp. 238-252)._

## Research question / purpose
- Solve mixed-variables programs max { c^T x + f(y) | A x + F(y) <= b, x >= 0, y in S } (eq. 1.1, p. 238), where x is continuous and enters linearly, and y lies in an arbitrary set S (e.g. integers) and may enter nonlinearly through f and F (p. 238).
- Idea: partition the problem into a programming problem in y (any type: linear, nonlinear, discrete) and an LP in x, and avoid computing the complete set of constraints that define the feasible region of the y-problem; instead generate only the constraints needed, in a finite multi-step procedure (pp. 238-239).
- Motivating examples: mixed-integer programs (p. 238), problems with some variables nonlinear (Griffith and Stewart), and LPs with block structure linked by some columns (p. 238; Dantzig-Wolfe mentioned as the method for block structures).
- Presented at the 8th TIMS meeting, Brussels 1961; based on the author's 1960 Utrecht thesis; author at Koninklijke/Shell-Laboratorium, Amsterdam (pp. 238-239).

## Setting
- **System:** none (general mathematical programming). Only a small test MILP is reported (p. 251).
- **Markets:** n/a.
- **Horizon and resolution:** n/a; static (single-period) problem. No stochastic or multistage content.

## Method
- **Model type:** deterministic mixed-variables (MILP / mixed nonlinear) program in **maximisation** form (eq. 1.1, p. 238).
- **How uncertainty is represented:** not at all.
- **Solution method:**
  - *Preliminaries (p. 239):* cone C = {(u0, u) | A^T u - c u0 >= 0, u >= 0, u0 >= 0} (eq. 2.1); cone C0 = {u | A^T u >= 0, u >= 0} (eq. 2.2); dual polyhedron P = {u | A^T u >= c, u >= 0} (eq. 2.3).
  - *Equivalent form* with scalar x0 for the objective (eq. 3.1, p. 239).
  - *Projection (pp. 240-241):* by Farkas' lemma, (x0, y) is feasible iff u0 x0 + u^T F(y) - u0 f(y) <= u^T b for every (u0, u) in C. Since C is a pointed polyhedral cone it is generated by finitely many extreme half-lines, so the projected set G is defined by finitely many such constraints (eqs. 3.2-3.4, p. 240).
  - *Partitioning theorem (Theorem 3.1, p. 240):* (1.1) infeasible iff max{x0 | (x0, y) in G} (eq. 3.5) infeasible; unbounded iff (3.5) unbounded; optimal y-bar of (3.5) plus the LP in x for fixed y-bar (eq. 3.6) gives an optimal solution of (1.1). Proof via Farkas (pp. 240-241).
  - *Practicality (p. 241):* computing all extreme half-lines of C is "practically impossible"; it suffices to generate the constraints that determine the optimum.
  - *Relaxed master (p. 242):* for a finite subset Q of C, G(Q) is a relaxation and max{x0 | (x0, y) in G(Q)} (eq. 4.4) gives an upper bound. Lemma 4.1 (p. 241): with S bounded, x0 is unbounded on G iff P is empty. Lemma 4.2 (p. 242): the master optimum (x0-bar, y-bar) is optimal for (3.5) iff min{(b - F(y-bar))^T u | u in P} = x0-bar - f(y-bar) (eq. 4.5).
  - *Cut generation (p. 243-244):* solve the LP subproblem min{(b - F(y-bar))^T u | u in P} (dual of the x-LP for fixed y). If its optimum vertex u-bar violates (4.5) (eq. 4.13), add (1, u-bar) to Q, i.e. the constraint x0 + u-bar^T F(y) - f(y) <= u-bar^T b (today's *optimality cut*). If the subproblem is unbounded along an extreme ray v-bar of C0 (eq. 4.14), add (0, v-bar), i.e. v-bar^T F(y) <= v-bar^T b (today's *feasibility cut*). Both can be added at once (p. 244). Benders does not use the words "master problem", "optimality cut" or "feasibility cut".
  - *Procedure 4.1 (pp. 244-246):* initial step; iterative step part 1 = solve master (4.20); part 2 = solve LP (4.21); terminate when (4.22) holds, otherwise extend Q (4.24, 4.26, 4.28). Finite termination because each non-terminal step adds at least one new extreme half-line of C (p. 245).
  - *Bounds (pp. 245-246):* master values x0^nu are non-increasing (4.29); at each step max_k {(b - F(y^k))^T u^k + f(y^k)} <= optimum <= x0^nu (eq. 4.33, p. 246), i.e. the subproblem gives a **lower** bound and the relaxed master an **upper** bound (maximisation). Q0 can start as the origin with x0 = +infinity (p. 246).
  - *Procedure 5.1 (pp. 246-249):* solve the primal LP (5.1) instead of the dual, using a big-M bounded polyhedron P(M) and artificial variable z0 (eqs. 5.2-5.4) so the LP is always feasible; recover the dual vertex and extreme ray from the "M-components" of the simplex d-row (eqs. 5.8-5.16, pp. 247-248); bounds (5.24, p. 249); how to choose M (p. 249); vector z variant (5.25) and only adding artificial variables for rows containing y (5.28, p. 250).
  - *Applications (Sec. VI, pp. 250-251):* (a) S polyhedral, F and f linear: master is an LP, dual simplex suited; the procedures are then special versions of Dantzig-Wolfe decomposition (p. 250). (b) Convex differentiable f, F: master is convex, solvable e.g. by Kelley's cutting plane, Rosen's gradient projection or Zoutendijk (p. 250). (c) Mixed-integer linear: master is an integer program solvable by Gomory cuts; 0-1 case via Benders-Catchpole-Kuiken combinatorial method, practical up to about 30-40 binaries on the Ferranti Mark I* (pp. 250-251).
- **Key modelling choices and assumptions:** x enters linearly; S closed and bounded and f, F continuous on a set containing S (p. 241); add artificial bounds on y if S is unbounded (p. 241).

## Data / case
- One typical test MILP: 29 continuous variables, 27 integer (0-1) variables, 34 linear constraints; solved in 11 steps with Procedure 5.1 (variant 5.25) and the combinatorial 0-1 method (p. 251).
- Table of successive bounds: upper bound from +infinity to 233.37, 191.37, ... 179.75; lower bound from -infinity to 152.58, 176.19, 179.45, ... 179.75 (p. 251).

## Key findings
- (p. 240) Theorem 3.1: the mixed-variables problem is equivalent to a problem in (x0, y) defined by finitely many constraints from extreme half-lines of the dual cone C, plus an LP in x for fixed y.
- (p. 241) Enumerating all those constraints is practically impossible; generate only those needed for the optimum.
- (pp. 242-244) Optimality test (Lemma 4.2) and two types of generated constraints: from dual vertices (1, u) and from dual extreme rays (0, v).
- (p. 245) The procedure terminates in a finite number of steps (infeasible, unbounded or optimal).
- (p. 246) Upper and lower bounds on the optimum at every step (eq. 4.33).
- (p. 250) For linear problems the procedure is a special version of Dantzig-Wolfe decomposition; for convex problems the master can use Kelley's cutting plane.
- (p. 251) No useful theoretical estimates of the number of steps exist; in the test cases the number of steps was "encouragingly small", bounds were instructive for judging the rate of convergence, and most time was spent in the LP subproblem; adding more than one or two constraints per step might reduce the number of steps (multi-cut idea, not worked out).

## Strengths
- General: master can be any problem type; LP duality supplies all cut information.
- Bounds at every iteration give a natural convergence monitor.
- Explicit distinction between the two cut types, and finite termination.

## Weaknesses / limitations
- Deterministic and single-period; nothing on stochastic or multistage problems (later L-shaped, nested decomposition and SDDP extend it).
- Computational evidence is minimal (one test case reported in detail).
- No guidance on cut management (stated as not yet worked out, p. 251).
- Notation and big-M "d-row" machinery (Sec. V) are dated.
